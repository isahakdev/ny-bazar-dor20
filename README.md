# বাজার দর (BazarDor) 🛒

BazarDor is a web application where users can check daily product prices in Bangladesh, browse categories, and view product details.

## ✨ Features

- View all products and their prices.
- Browse products by category.
- See products with increased and decreased prices.
- Sort products by price.
- View product details and market prices.
- Sign up and sign in using Better Auth.
- Responsive design for mobile, tablet, and desktop.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
